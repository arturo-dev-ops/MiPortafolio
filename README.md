# Portafolio profesional — Arturo Jiménez Aparicio

Sitio web personal para presentar el perfil de Arturo Jiménez Aparicio como Desarrollador Web Full Stack y Técnico de Sistemas. Reúne información profesional, habilidades, formación, experiencia, contacto y proyectos destacados en una página responsive.

También puedes visitar mi [perfil de GitHub](https://github.com/arturo-dev-ops), donde presento mi perfil y otros repositorios.

## ¿Qué hace?

- Presenta el perfil profesional y la disponibilidad para prácticas o trabajo.
- Muestra las habilidades técnicas organizadas en pestañas interactivas.
- Permite filtrar las tarjetas de proyectos por categoría.
- Incluye experiencia laboral, formación y datos de contacto.
- El menú móvil se despliega y permite navegar por las secciones.
- El botón **Descargar CV** abre la ventana de impresión del navegador para imprimirlo o guardarlo como PDF.
- El formulario valida los campos y prepara un correo mediante `mailto:`. No envía mensajes a un servidor; requiere una aplicación de correo configurada.

Las tarjetas de proyectos describen los proyectos destacados en el portafolio; el sitio no incluye la implementación funcional de esas aplicaciones.

## Tecnologías

- HTML5
- CSS3 y Tailwind CSS por CDN
- JavaScript
- Font Awesome por CDN

Tailwind CSS y Font Awesome requieren conexión a Internet para cargar desde sus CDN.

## Estructura

```text
MiPortafolio/
├── index.html
├── README.md
├── css/
│   └── styles.css
└── js/
    └── script.js
```

## Cómo verlo

Abre `index.html` en un navegador o usa una extensión como **Live Server** en Visual Studio Code.

## Personalización

- Edita el contenido y las secciones en `index.html`.
- Modifica los estilos propios en `css/styles.css`.
- Cambia las interacciones y validaciones en `js/script.js`.
